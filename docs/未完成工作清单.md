
> ⚠️ **本机到服务器这条路上的 SSH 会被中间设备杀**（`kex_exchange_identification` reset，
> 服务端 banner 一个字节都收不到；服务器侧一切正常：sshd 在听、云防火墙 22 全开、
> 你的 IP 没被任何规则拉黑）。所以**传文件改走腾讯云控制台 → 文件管理**上传 tar 包，
> 命令在**网页终端**里跑：
>
> ```bash
> # 本机
> cd /Users/fangmengdi/Documents/back-end/Agent/deploy-kit
> tar czf ~/Desktop/deploy-kit-server.tar.gz server/
> # 控制台「文件管理」上传，然后在网页终端里：
> sudo tar xzf /root/deploy-kit-server.tar.gz -C "$HOME"
> cd ~/server && sudo bash install-server.sh --project xuexu --dry-run
> ```
>
> **这不影响 CI**：GitHub 的 runner 在 Azure，走的是另一条路。
